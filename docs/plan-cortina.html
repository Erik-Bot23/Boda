1. El roadmap reordenado

El cliente pidió música de fondo. Como los navegadores bloquean el sonido automático, hace falta una pantalla inicial que pida un clic. Eso se convirtió en una cortina de bienvenida, y empujó el RSVP al final.

FaseSecciónQué implicaTipo
16DespedidaAgradecimiento de cierre. Implementada; falta el degradado y un typo.estático
17FooterCierre oscuro con foto y texto arenaestático
18Cortina + músicaPantalla inicial a pantalla completa; un clic abre la página y suena la cancióncliente
19RSVP + OracleFormulario, server action y persistencia. Puede ser sección o modal.cliente + servidor
Por qué la cortina va antes del RSVP: el RSVP es lo único que depende de una cuenta en Oracle Cloud, credenciales y variables de entorno. Todo lo visual debe estar cerrado antes. La cortina, en cambio, es un componente nuevo que no toca ninguna sección.

1.1 Estado de la página hoy

app/layout.tsx └── body └── Cortina (fijo, por encima de todo) ← Fase 18 ├── audio (la canción, en loop) app/page.tsx └── main ├── Hero → Bienvenida → NuestraHistoria → CuentaRegresiva ├── ElGranDia → Cronograma → CodigoVestimenta → Hospedaje ├── Galeria → PreguntasFrecuentes → Despedida ├── Rsvp (cuando exista; va antes de Despedida) └── Footer ← Fase 17
El RSVP puede no existir como sección. Si el cliente prefiere que el RSVP sea un modal que se abre al dar clic en "Confirmar" (el botón del Header), entonces no hay ninguna sección entre PreguntasFrecuentes y Despedida. Eso cambia el diseño de la transición y se trata en la sección 4.

2. La cortina de bienvenida, a fondo

2.1 El problema que resuelve

Los navegadores modernos bloquean el audio que empieza solo. Chrome, Safari y Firefox exigen que el usuario interactúe con la página antes de permitir la reproducción. Es una medida contra las páginas que suenan sin permiso.

La solución clásica es exactamente la que pidió el cliente: una pantalla que dice "entra" y que, al recibir el clic, aprovecha ese gesto para arrancar el audio. El clic del usuario es el permiso.

Regla: el audio se crea, pero play() solo se llama dentro del manejador del clic. Si lo llamas en un useEffect al cargar la página, el navegador lo ignora y la consola muestra un error de autoplay.

2.2 Los tres estados de la cortina

┌──────────────────────────────┐ │ mostrar = true, abierta = false │ ← visible, bloquea el scroll └──────────────┬───────────────────┘ │ clic en "Entrar" ▼ ┌──────────────────────────────┐ │ mostrar = true, abierta = true │ ← se desvanece (1 s) └──────────────┬───────────────────┘ │ termina la transición ▼ ┌──────────────────────────────┐ │ mostrar = false │ ← desmontada, el audio sigue └──────────────────────────────┘

El tercer estado es el que permite desmontar la cortina: si se quitara del DOM en el mismo instante del clic, no habría transición y la página aparecería de golpe.

2.3 Los datos

//data/wedding-data.ts
export const music = {
    //Si renombrar el archivo a "cancion.mp3", la ruta es simplemente "/music/cancion.mp3"
    src: "/music/Opalite%20(Life%20Is%20A%20Song%20Acoustic%20Version).mp3",
} as const;

%20 es el espacio codificado. El navegador lo decodifica y Next entrega el archivo. Los paréntesis no hace falta codificarlos, pero los espacios sí.

2.4 El componente completo, explicado

"use client";

import { useCallback, useEffect, useRef, useState, useSyncExternalStore } from "react";
import type { ReactNode } from "react";
import { couple, event, music } from "@/data/wedding-data";

const QUERY_REDUCIR = "(prefers-reduced-motion: reduce)";

function getSnapshot() {
    return window.matchMedia(QUERY_REDUCIR).matches;
}
function getServerSnapshot() {
    return false;
}
function subscribe(callback: () => void) {
    const mq = window.matchMedia(QUERY_REDUCIR);
    mq.addEventListener("change", callback);
    return () => mq.removeEventListener("change", callback);
}

export default function Cortina({ children }: { children: ReactNode }) {
    const audioRef = useRef<HTMLAudioElement>(null);
    const [mostrar, setMostrar] = useState(true);
    const [abierta, setAbierta] = useState(false);
    const reducir = useSyncExternalStore(subscribe, getSnapshot, getServerSnapshot);

    //Mientras la cortina está arriba, la página no se puede desplazar
    useEffect(() => {
        document.body.style.overflow = mostrar ? "hidden" : "";
    }, [mostrar]);

    const entrar = useCallback(() => {
        //El clic es el gesto que desbloquea el autoplay
        const audio = audioRef.current;
        if (audio) {
            audio.volume = 0.6;
            audio.play().catch(() => {});
        }

        setAbierta(true);
        window.setTimeout(() => setMostrar(false), reducir ? 0 : 1000);
    }, [reducir]);

    return (
        <>
            {children}

            {mostrar ? (
                <button
                    type="button"
                    onClick={entrar}
                    aria-label="Entrar a la invitación"
                    className={`cortina fixed inset-0 z-[100] flex cursor-pointer flex-col
                                items-center justify-center gap-6 bg-ink px-6 text-center
                                ${reducir ? "transition-none" : "transition-opacity duration-1000"}
                                ${abierta ? "pointer-events-none opacity-0" : "opacity-100"}`}>

                    <span className="font-sans text-[11px] uppercase tracking-[0.45em] text-terracotta">
                        Nuestra boda
                    </span>

                    <span className="font-serif text-5xl leading-none text-cream md:text-7xl">
                        {couple.groom} & {couple.bride}
                    </span>

                    <span className="h-px w-16 bg-terracotta/60" />

                    <span className="font-sans text-xs uppercase tracking-[0.3em] text-sand">
                        {event.dateLabel}
                    </span>

                    <span className="mt-6 inline-flex items-center gap-3 rounded-full border
                                   border-cream/40 px-8 py-3 font-sans text-[11px] uppercase
                                   tracking-[0.25em] text-cream">
                        Entrar
                    </span>
                </button>
            ) : null}

            <audio ref={audioRef} src={music.src} loop preload="none" />
        </>
    );
}

2.5 Por qué cada decisión

DetalleRazón
Envuelve a {children} con un <>…</>Si Cortina renderizara un <div>, rompería el flex flex-col del <body> y el Footer dejaría de quedar al fondo. Un fragmento no existe en el DOM
El overlay es un <button>Así es clickeable con el mouse y con el teclado (Tab + Enter). Un <div> con onClick no es accesible
Dentro solo van <span>Un <button> solo admite contenido en línea. Un <p> o un <h1> adentro sería HTML inválido
aria-label="Entrar a la invitación"El nombre accesible del botón no es todo el texto visual; es una frase corta y clara
z-[100]El Header usa z-50. La cortina tiene que quedar por encima de todo, incluido el menú
fixed inset-0No ocupa lugar en el flujo: la página se renderiza y se posiciona normalmente detrás
Bloqueo de scroll con document.body.style.overflowSin esto, la página se desplazaría detrás de la cortina. Se restaura al abrir
preload="none" en el audioEl archivo pesa 5.5 MB. Si se precarga, la página tarda más en cargar sin que nadie haya oído nada. Al hacer clic, el navegador empieza a descargarlo
audio.volume = 0.6La música de fondo no debe competir con la lectura. 60 % es un buen punto de partida
.catch(() => {})Si el navegador sigue negando el sonido (por política estricta), la página debe abrirse igual. El error se traga en silencio
useSyncExternalStoreEvita el error de ESLint react-hooks/set-state-in-effect al leer prefers-reduced-motion (ya documentado en el carrusel)
pointer-events-none al desvanecerDurante la transición de salida, el overlay ya no debe interceptar clics
transition-none si reducirQuien pidió reducir animaciones no debe esperar un segundo de fundido

2.6 El layout

//app/layout.tsx
import Cortina from "@/components/layout/Cortina";

export default function RootLayout({ children }: LayoutProps<"/">) {
  return (
    <html lang="es" className={`${cormorant.variable} ${montserrat.variable} h-full`}>
      <body className="flex min-h-full flex-col">
        <Cortina>{children}</Cortina>
      </body>
    </html>
  );
}
Sin JavaScript no hay cortina. La cortina se renderiza en el servidor, así que aparece aunque el JavaScript falle. Pero si el JavaScript no carga nunca, la página quedaría tapada. Para cubrir ese caso extremo, se puede agregar un <noscript> que la oculte: 
<noscript>
  <style>{`.cortina { display: none !important; }`}</style>
</noscript>

La clase cortina ya está puesta en el botón del overlay, así que solo hay que agregar ese bloque dentro del fragmento de Cortina.

3. La música de fondo

DatoValor
Archivopublic/music/Opalite (Life Is A Song Acoustic Version).mp3
Peso5.56 MB
Ruta web/music/Opalite%20(Life%20Is%20A%20Song%20Acoustic%20Version).mp3

3.1 Renombrar el archivo (recomendado)

Los espacios y los paréntesis en una URL son fuente de problemas: hay que codificarlos, algunos servidores se quejan y es fácil equivocarse al escribir la ruta. Lo más limpio es renombrarlo desde el explorador a algo simple:

public/music/cancion.mp3

Y entonces los datos quedan mucho más claros:

export const music = {
    src: "/music/cancion.mp3",
} as const;
Renombrar no rompe nada: ninguna sección apunta a esa ruta todavía. Es el momento ideal para hacerlo.

3.2 El peso importa

5.56 MB es mucho para una canción de fondo en una página que se abre desde WhatsApp. La versión acústica a 128 kbps estaría alrededor de 1.5 MB, casi sin pérdida perceptible en un teléfono. Se puede bajar con cualquier convertidor (Audacity, o servicios en línea) eligiendo MP3 a 128 kbps.

Mientras tanto, preload="none" evita que ese peso ralentice la carga inicial: el archivo solo se descarga cuando el invitado hace clic en "Entrar".

3.3 Un botón para silenciar (opcional)

Música de fondo que no se puede parar es una queja clásica. Un botón flotante pequeño resuelve el problema:

//Dentro de Cortina, después del <audio>
const [silenciado, setSilenciado] = useState(false);

const alternarSonido = useCallback(() => {
    const audio = audioRef.current;
    if (!audio) return;
    audio.muted = !audio.muted;
    setSilenciado(audio.muted);
}, []);

// Botón flotante, visible solo cuando la cortina ya se quitó
{!mostrar ? (
    <button
        type="button"
        onClick={alternarSonido}
        aria-label={silenciado ? "Activar música" : "Silenciar música"}
        className="fixed bottom-5 right-5 z-[90] flex h-11 w-11 items-center justify-center
                   rounded-full border border-sand/60 bg-cream/90 text-coffee shadow-lg
                   transition-colors duration-300 hover:bg-cream">
        {silenciado ? "🔇" : "🎵"}
    </button>) : null}
Emojis en la interfaz: funcionan, pero su aspecto cambia según el sistema operativo. Para el sitio final conviene usar un ícono SVG. Como prototipo, el emoji es suficiente.

4. El degradado de la Despedida

4.1 El problema

El cliente eligió bg-ink para la Despedida. El problema es lo que tiene alrededor:

PreguntasFrecuentes bg-coffee #5C3A21 │ │ ← salto brusco ▼ Despedida bg-ink #1A1817

Dos oscuros distintos pegados se sienten como un error: el ojo espera una transición, no un corte.

4.2 La solución: un degradado que conecta con ambos

<section id="despedida" className="scroll-mt-24 bg-linear-to-b from-coffee to-ink py-24">

Así queda la cadena completa, y los dos bordes coinciden con lo que tienen al lado:

LímiteColor de arribaColor de abajoResultado
FAQ → Despedidacoffee (abajo del FAQ)from-coffee (arriba del degradado)continuo, sin costura
Despedida → Footerto-ink (abajo del degradado)bg-ink + foto del Footercontinuo, sin costura

El texto crema en el centro del degradado (un marrón intermedio, ~#3B291C) mantiene contraste de sobra.

Por qué bg-linear-to-b y no un divisor: es una sola clase, no agrega elementos ni JavaScript, y resuelve los dos límites de una sola vez. Si algún día el Footer cambia de color, solo hay que ajustar el to-*.

4.3 Alternativa decorativa (opcional)

Si se quiere un cierre más editorial, se puede poner una onda SVG como la del Cronograma entre el FAQ y la Despedida. Es más trabajo (un SVG + alinear los extremos) y no aporta mucho en una transición entre dos oscuros. El degradado es la opción práctica.

5. Hoteles con fotografía

5.1 Cómo funciona hoy

La sección Hospedaje ya está conectada a los datos: si agregas entradas al arreglo hotels en data/wedding-data.ts, aparecen solas en la cuadrícula. No hay que tocar el componente.

export const hotels: Hotel[] = [
    { name: "Hotel Ejemplo", note: "A 10 minutos del evento", url: "https://..." },
];

5.2 Agregar imágenes

Sí se puede. Son tres cambios chicos.

1. El tipo

export type Hotel = {
    name: string;
    note: string;
    url: string | null;
    //Foto del hotel (opcional). Ruta en public/, por ejemplo /images/hotel-1.jpg
    image?: string;
    //Texto alternativo de la foto; si falta, se usa el nombre del hotel
    imageAlt?: string;
}

2. Los datos

export const hotels: Hotel[] = [
    {
        name: "Hotel Ejemplo",
        note: "A 10 minutos del evento, con estacionamiento.",
        url: "https://...",
        image: "/images/hotel-ejemplo.jpg",
        imageAlt: "Entrada del Hotel Ejemplo",
    },
];

3. El componente

Dentro del <li> de Hospedaje.tsx, antes del <h3> con el nombre:

{hotel.image ? (
    <div className="relative mb-5 aspect-[16/10] overflow-hidden rounded-xl">
        <Image
            src={hotel.image}
            alt={hotel.imageAlt ?? hotel.name}
            fill
            sizes="(min-width: 1024px) 33vw, 50vw"

DetalleRazón
image? opcionalLos hoteles sin foto siguen funcionando igual. No hay que llenar todos los campos
aspect-[16/10]Marco uniforme: aunque las fotos tengan distinta proporción, las cards quedan parejas

6. El RSVP: sección o modal

El cliente dejó abierta la posibilidad de que el RSVP no sea una sección sino un modal que se abra al dar clic en el botón "Confirmar" del Header. Ambas opciones son válidas; esto es lo que cambia.

AspectoComo secciónComo modal
Dónde viveEntre FAQ y Despedida, con ancla #rsvpEn un <dialog> o componente de modal, abierto desde el Header
El HeaderEl botón "Confirmar" es un <a href="#rsvp">El botón es un <button> que abre el modal
La DespedidaVa después del RSVPVa inmediatamente después del FAQ
La transiciónFAQ (café) → RSVP (crema) → Despedida (degradado)FAQ (café) → Despedida (degradado). El degradado es aún más necesario
EstadoUn useState en la páginaEl estado del modal puede vivir en el Header (cliente)
URLSe puede compartir …#rsvp y que ya esté ahíNo hay ancla; se abre con un clic
Recomendación: para una boda, la sección es más simple y más fácil de encontrar (mucha gente baja hasta el final). El modal es más elegante, pero esconde el formulario detrás de un clic. Como el cliente lo pidió "para el final", se decide cuando lleguemos.

6.1 Oracle sigue igual

Sea sección o modal, el servidor action y la conexión a Oracle no cambian: oracledb en modo thin, un pool singleton en globalThis, bind variables y variables de entorno sin NEXT_PUBLIC_. Todo eso está detallado en docs/plan-fases.pdf.

7. Errores típicos y checklist

7.1 Errores típicos de la cortina

SíntomaCausa
La cortina no apareceSe renderizó con mostrar = false, o el componente no está en el layout
La página no se desplazaba después de entrarFalta restaurar document.body.style.overflow
El audio no suenaSe llamó play() fuera del clic, o el archivo no existe en public/music/
Error 404 del audioEspacios sin codificar en la ruta, o el nombre del archivo no coincide exactamente
El menú del Header queda por encima de la cortinaFalta z-[100] (el Header usa z-50)
La cortina se ve en la pantalla de cargas pero la página parpadea al abrirFalta pointer-events-none durante la transición
Error de ESLint al leer matchMediaSe usó setState en el cuerpo de un efecto; la solución es useSyncExternalStore
El lector de pantalla lee todo el texto de la cortina como un botón giganteFalta el aria-label en el <button>

7.2 Checklist de la Fase 18

  • Al abrir el sitio, la cortina cubre todo: nombres, fecha y "Entrar".
  • El clic abre la página con un fundido de un segundo.
  • La música empieza con el clic y se repite en loop.
  • Se puede seguir navegando con el teclado: Tab llega al botón "Entrar", Enter abre.
  • Con "reducir animaciones" activado, la cortina desaparece al instante.
  • Si el JavaScript no carga, la página sigue accesible (gracias al <noscript>).
  • npx tsc --noEmit y npx eslint . limpios.
